# S-Series_v3

This project is an Rc-Car. It is my 9th Rc-Car to be exact, but the 6th one when you exclude the ones I never finished.

## Why I Made This (and a little bit of history)

Even tho I never cared for rc cars this project line still has a special place in my heart. That's because the first, real project I've ever made was an rc car. It was a really bad one, it didn't even have a function to steer, but that all changed on the second version, where I introduced steering. For the 5th version I made a much better steering system and fixed the many flaws of the 2nd version. The 6th version was a failed experiment, it was meant to be a front wheel drive with thinner parts and custom wheel. Honestly the idea wasn't bad but the wheels had no grip and kind of made the whole project unusable. The 7th version was the first version with suspension, even tho it was very experimental and the suspension didn't work properly it was still much more stable and ridged than the older version. Now the 9th version and it's even more stable and the suspension actually works. This is the first version I'll feel comfortable driving for longer periods.
