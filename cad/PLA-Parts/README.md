## 3D Printing Instructions

Print all parts in **PLA**.

Most parts can be sliced and printed normally. Use your slicer's default PLA settings unless a specific part needs extra strength or support.

## Ball Joint Parts

When importing the ball joint files into your slicer, select the following files together:

* Connector
* Ball
* Ball2
* Sphere

When the slicer asks:

> Load these files as a single object with multiple parts?

Select **Yes**.

This keeps the ball joint parts aligned correctly for printing.

## Notes

* Check the part orientation before printing. Some orientations might be stronger.
* Add supports if your slicer shows large overhangs.
* Make sure all ball joint pieces stay in their correct positions when loaded.
